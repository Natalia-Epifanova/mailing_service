# Mailing Service (Django)

Сервис управления email-рассылками с возможностями:
- Создания и управления рассылками
- Работы с получателями и сообщениями
- Просмотра статистики
- Аутентификации и авторизации пользователей

## Установка:
1. Клонируйте репозиторий:
```https://github.com/Natalia-Epifanova/mailing_service```
2. Установите зависимости:
```pip install -r requirements.txt```
3. Создайте и активируйте виртуальное окружение: 
- ```python -m venv venv```
- ```source venv/bin/activate```  # Linux/Mac
- ```venv\Scripts\activate```  # Windows
4. Выполнить миграции: ```python manage.py migrate```
5. Создать суперпользователя: ```python manage.py csu```
6. Запустить сервер: ```python manage.py runserver```

## 📌 Основные возможности

### Аутентификация и авторизация
- Регистрация с подтверждением email
- Вход/выход из системы
- Разграничение прав доступа (пользователи, менеджеры)
- Блокировка/разблокировка пользователей

### Управление рассылками
- Создание/редактирование/удаление рассылок
- Просмотр статистики по отправкам
- Автоматическая остановка рассылок при блокировке пользователя

### Работа с сообщениями и получателями
- Создание/редактирование/удаление получателей
- Создание/редактирование/удаление писем


## Технологический стек
- Python 3.11
- Django 4.2.2
- redis 6.0.0
- psycopg2 2.9.10
- psycopg2-binary 2.9.10


## 🌐 Доступы
После запуска проект доступен по адресу: http://127.0.0.1:8000

Тестовые пользователи:

- Менеджер: manager@example.com / managerpass (команда для создания ```python manage.py create_manager```)


- Обычный пользователь: user@example.com / userpass (команда для создания ```python manage.py create_custom_user```)

## Логирование
Система логирования настроена на запись в папку logs:

Файл mailing.log


## Развертывание в production
Настроить .env файл с переменными окружения (смотреть файл .env.example)

Использовать PostgreSQL вместо SQLite

Настроить Redis для асинхронных задач
